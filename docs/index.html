Read the documents

PDF, DOCX, text, Markdown, and HTML are parsed into searchable passages with page or document references.

02 / RETRIEVE

Find relevant evidence

Account-scoped vector search and term overlap select passages before a model drafts an answer.

03 / ANSWER

Cite or hand off

Answers include source references. When the available material cannot support a response, the assistant directs the customer to support.
